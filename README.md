### 🧱 [DataDose](https://github.com/Youssef-Adel91/DataDose): Clinical Decision Intelligence Platform
My **DEPI graduation project**, built with my team. It combines a Neo4j drug-interaction knowledge graph, real-time streaming, and a GraphRAG assistant with a full data engineering pipeline.
- **My role:** Big Data & Pipeline Orchestration Engineer
- Built and debugged the **Databricks PySpark** streaming pipeline (Kafka → Neo4j enrichment → Snowflake)
- Designed a **two-layer Airflow orchestration**: a streaming supervision DAG and a batch medallion promotion DAG
- Wrote the technical documentation covering the full stack
- `Databricks` `PySpark` `Airflow` `Docker` `Kafka` `Snowflake` `Neo4j` `FastAPI` `Next.js`

### 🏎️ [CURT Inventory Assistant](https://github.com/aligad12/curt-inventory-assistant)
A conversational parts-inventory assistant for the **Cairo University Racing Team**, built in two phases: a rule-based assistant, then an **LLM (Gemini) with function/tool calling** and multi-turn memory. The model never touches SQL; it can only call controlled tools.
- `Python` `FastAPI` `Streamlit` `Gemini` `Tool Calling` `SQLite`

## 🧠 Deep Learning From the Ground Up

In the **Automatic Computing** course with **Dr. Meena Abd El Maseeh**, I went beyond using frameworks and rebuilt how they work:

| Topic | What I covered |
|---|---|
| ⚙️ **Autograd** | Reverse-mode automatic differentiation, implemented from scratch |
| 🕸️ **Computational graphs** | Building the graph and propagating gradients through it |
| 🔁 **Reverse topological sort** | Ordering the graph so gradients flow in the correct order |
| 📉 **Optimization** | Stochastic gradient descent and mini-batch gradient descent |
| 🏗️ **Architectures** | CNNs and RNNs |

### 🦈 [Project Sentinel](https://github.com/aligad12/nasaSharkTag): NASA Space Apps Cairo, 🏆 1st Place
> A predictive platform that fuses NASA satellite data with an AI-powered smart shark tag to forecast foraging hotspots, so conservation areas can move with the animals instead of staying fixed on a map.

**Team Maritime Orbiters.** I was part of the AI team.
- **Won 1st place** at the NASA Space Apps Cairo hackathon and a **10,000 EGP prize**
- A **three-layer ML framework**: a Random Forest hotspot classifier, a Markov-chain trajectory forecaster, and a Random Forest regressor for tag-level behavior
- Fuses **NASA MODIS, SWOT and PACE** satellite data into one analysis grid, with a smart-tag design that uses a Markov model to save battery

`Python` `scikit-learn` `Pandas` `Random Forest` `Markov Chains` `NASA Earth Data` `TinyML`

### 🧱 [DataDose](https://github.com/Youssef-Adel91/DataDose): Clinical Decision Intelligence Platform
> My **DEPI graduation project**, built with a team. It combines a Neo4j drug-interaction knowledge graph, real-time streaming, and a GraphRAG assistant on top of a full data engineering pipeline.

**My role:** Big Data & Pipeline Orchestration Engineer
- Built and debugged the **Databricks PySpark** streaming pipeline: Kafka → Neo4j enrichment → Snowflake
- Designed a **two-layer Airflow orchestration**: a streaming supervision DAG plus a batch medallion promotion DAG
- Wrote the technical documentation for the full stack

`Databricks` `PySpark` `Airflow` `Docker` `Kafka` `Snowflake` `Neo4j` `FastAPI` `Next.js`

### 🏎️ [CURT Inventory Assistant](https://github.com/aligad12/curt-inventory-assistant): LLM Tool-Calling Assistant
> A conversational parts-inventory assistant for the **Cairo University Racing Team**.

- Built in two phases: a rule-based assistant first, then an **LLM (Gemini) with function/tool calling** and multi-turn memory
- **Safe by design:** the model never touches SQL, it can only call controlled tools

`Python` `FastAPI` `Streamlit` `Gemini` `Tool Calling` `SQLite`

### 📦 [BookETL](https://github.com/aligad12/booketl): Scraping & Analytics Pipeline
> An end-to-end pipeline, from raw web pages to tested analytics tables.

- Scrapes **1,000 products across 50 categories**, then cleans and validates the data with Pandas
- Loads into **Snowflake** and transforms with **dbt**
- Tests every layer: dbt schema tests plus pytest

`Python` `BeautifulSoup` `Pandas` `Snowflake` `dbt` `pytest`

## 🧠 Deep Learning From the Ground Up

In the **Automatic Computing** course with **Dr. Meena Abd El Maseeh**, I went beyond using frameworks and rebuilt how they work.

| Topic | What I built or covered |
|---|---|
| ⚙️ **Autograd** | Reverse-mode automatic differentiation, implemented from scratch |
| 🕸️ **Computational graphs** | Building the graph and propagating gradients through it |
| 🔁 **Reverse topological sort** | Ordering the graph so gradients flow in the correct order |
| 📉 **Optimization** | Stochastic and mini-batch gradient descent |
| 🏗️ **Architectures** | CNNs and RNNs, including an **RNN with BPTT** validated against PyTorch |
